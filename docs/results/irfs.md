# Dynamic Responses to an Innovation-Cost Reduction

Impulse response functions (IRFs) describe how the structural model responds to a specified innovation-cost shock, holding other shocks at zero. Responses are **model-conditional**, and their quantitative interpretation requires the shock magnitude, variable transformations and calibration to be stated explicitly.

## Reporting checklist

Before using these as Welsh policy impacts, document the precise definition and unit of the innovation-cost parameter `tau`, whether the innovation-cost reduction is temporary or permanent, the size and persistence of the shock, regional aggregation weights, and whether the variables are log deviations or percentage-point changes. Do not equate an arbitrary model innovation with an equal-fiscal-cost public policy by default.
